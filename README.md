# ilvl

Официальные установщики ilvl для macOS.

- [Сайт и скачивание](https://ilvl.ru/download/)
- [Последний релиз](https://github.com/ilovehackit/ilvl-official/releases/latest)

Доступны версии для Apple Silicon и Intel. Требуется macOS 15.0 или новее.
Приложение подписывается сертификатом Apple Developer ID.
