## Что такое ilvl

ilvl помогает не отвлекаться на записи во время созвона. Приложение захватывает звук с микрофона и Mac, показывает транскрипцию в реальном времени, а после встречи собирает ключевые мысли, решения и задачи в структурированный конспект.

Работает без бота на встрече. По желанию можно включить локальную видеозапись выбранного экрана — она сохраняется на Mac и не отправляется в облако.

## Возможности

- запись микрофона и системного звука macOS;
- транскрипция разговора в реальном времени;
- структурированный конспект после встречи;
- шаблоны для 1:1, дейли, интервью, продаж, ретро и других встреч;
- чат по материалам заметки и транскрипта;
- папки, поиск и автоматические названия заметок;
- обнаружение активной встречи с предложением начать запись;
- глобальная диктовка по клавише `fn` в любое приложение;
- необязательная запись выбранного экрана в MP4 с просмотром внутри заметки и переходами по времени транскрипта;
- ilvl Cloud с синхронизацией текстовых заметок или работа через собственные API-ключи.

## Системные требования

- macOS 15.0 или новее;
- подключение к интернету для AI-функций;
- аккаунт ilvl Cloud или собственные API-ключи выбранных провайдеров;
- разрешения macOS на микрофон и запись системного звука;
- разрешение на запись экрана, если вы хотите сохранять видео встречи.

## Как это работает

1. Откройте ilvl и начните запись из заметки или компактной панели.
2. Во время встречи следите за живым транскриптом и добавляйте свои заметки.
3. Остановите запись — ilvl подготовит конспект с ключевыми моментами и задачами.
4. Задавайте вопросы по материалам встречи в чате заметки. Если была включена видеозапись, пересматривайте нужные моменты прямо в приложении.

ilvl работает с Zoom, Google Meet, Microsoft Teams, Яндекс Телемостом, Контур.Толком, Webex, FaceTime, Slack и другими приложениями, воспроизводящими звук на Mac.

## Подключение AI

В настройках можно выбрать один из двух режимов:

- **ilvl Cloud** — вход в аккаунт, синхронизация текстовых заметок, распознавание речи и AI-функции через сервер ilvl.
- **Свои API-ключи** — прямое подключение к выбранным провайдерам с вашими ключами. Для транскрипции поддерживаются OpenAI, Deepgram и Yandex SpeechKit; для конспекта и чата — OpenAI и YandexGPT.

## Приватность

- аудио- и видеозаписи сохраняются локально на Mac;
- в режиме ilvl Cloud текстовые заметки синхронизируются с аккаунтом, аудио передаётся через сервер ilvl партнёру распознавания, а текст и прикреплённые вами к чату изображения — для AI-обработки;
- в режиме собственных API-ключей аудио и текст отправляются напрямую выбранным провайдерам;
- видеозаписи экрана не отправляются ни на сервер ilvl, ни AI-провайдерам;
- запись экрана по умолчанию выключена и включается по вашему выбору с разрешением macOS;
- запись встречи не начинается без подтверждения пользователя;
- в приложении нет аналитики, рекламы и скрытой телеметрии.

## Цена

Скачать и установить ilvl можно бесплатно.

В режиме собственных API-ключей использование API оплачивается напрямую выбранному провайдеру по его тарифам.

## Установка

1. Скачайте DMG для процессора вашего Mac.
2. Откройте образ и перетащите ilvl в папку Applications.
3. Запустите приложение и выдайте запрошенные разрешения macOS.
4. В настройках войдите в ilvl Cloud или выберите режим собственных ключей и добавьте API-ключи.

Не знаете архитектуру Mac? Откройте ` → Об этом Mac`: строка «Чип» означает Apple Silicon, строка «Процессор» — Intel.
